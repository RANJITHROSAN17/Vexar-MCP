7 Bot Workflows — Notification Policy

Feature Upgrade Bot (Daily, Silent)

Proposes next queued task. Opens issue only if queued item exists; otherwise writes silent commit comment. No contributor notifications.

Issue Raise Bot (Mon 10:00, Silent)

Opens max 1 structured contributor issue per week from queued roadmap. Only appears in Issues tab — never @mentions watchers.

Issue Resolve Bot (On merge, Silent)

Reads PR body for "Closes #N"; verifies CI passed; closes linked issue; promotes next queued task. Only posts to linked issue.

Code Review Bot (On PR, Block/Pass)

Runs ruff + mypy + pytest (≥85%). Posts comment ONLY if gate fails. Zero noise when PR complies with Conventional Commits + labels.

Final Merge Bot (Only YOU — the only ping)

Runs only when review submitted by @RANJITHROSAN17 and all gates pass. Sends ONE notification to you. Zero auto-merge (ruleset blocks).

Welcome Bot (On issue/PR open, Silent)

Greets first-time contributors. Skips bot accounts and your account. Single comment with rules link — no ongoing notifications.

Stale Bot (Sun 00:00, Silent)

Weekly gentle reminder only for issues >90d old with zero activity. Never closes roadmap / good-first-issue / help-wanted / pinned.
